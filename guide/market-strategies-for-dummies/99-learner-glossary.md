# Learner glossary

← [For builders](13-for-builders-cohorts.md) · [TOC](README.md) · [Back to start →](00-start-here.md)

---

| Word | Simple meaning |
|---|---|
| **Candle** | Summary of open/high/low/close for a time box |
| **Closed candle** | Finished time box — safe to judge |
| **Level / zone** | Price area that previously mattered |
| **Support** | Area that bounced price up before |
| **Resistance** | Area that bounced price down before |
| **Trend** | Swings progressing up or down |
| **Chop / range** | Price rotating without clear progress |
| **Context** | Big-picture stance (question 1) |
| **Location** | Where your idea lives (question 2) |
| **Confirmation** | Closed-candle proof (question 3) |
| **FVG / imbalance** | Fast-move “gap” area that may be revisited |
| **Sweep** | Wick beyond a level + close back inside |
| **Acceptance** | Close beyond a level (break that sticks) |
| **Invalidation** | Price where your idea is wrong |
| **Wedge / flag / triangle** | Shape nicknames — tags, not full strategies |
| **Paper / dry-run** | Practice without real live risk on this stack |
| **Process grade** | Did you follow the checklist? (A/B/C) |
