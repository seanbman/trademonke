# Market Strategies for Dummies

### Learn to read markets using this project’s knowledge — while helping the builders improve the insight tools

This is the **learner track**. Plain language. Checklists. Practice first.

The **master / thesis track** (for developers and architects) lives one folder up: [../README.md](../README.md).

You do **not** need to read Capability Architecture to start here. Builders who already read the master guide will use your practice journals and feedback as real-world signal (yes — friendly guinea pigs).
