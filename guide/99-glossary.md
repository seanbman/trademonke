Quick reference for terms used across the book. Prefer platform definitions for automation.

## Capability Architecture

| Term | Meaning |
|---|---|
| **Capability** | Persistent ability to achieve a class of outcomes |
| **Capability definition** | Versioned governed spec (inputs, authority, outcomes, tests, lifecycle) |
| **Agent** | Bounded runtime realizing a capability |
| **Authority** | Machine-enforceable scope of action |
| **Observation** | Provenanced assertion about reality |
| **Event** | Recorded occurrence with identity and time |
| **Friction** | Repeated avoidable cost in work |
| **Control plane** | Policies, versions, rollout |
| **Operational plane** | Day-to-day processing |

## Order flow & auction

| Term | Meaning |
|---|---|
| **Balance** | Rotational auction accepting value |
| **Imbalance** | Directional discovery leaving thin areas |
| **Anchored VWAP** | Fair-value line from chosen pivot/session |
| **Volume profile** | Volume-at-price map |
| **POC / HVN / LVN** | Control / high-volume / low-volume nodes |
| **Footprint** | Bid×ask grid inside a candle |
| **Absorption** | Passiveive flow consumed without new extreme |
| **Delta** | Ask vs bid volume imbalance metric |

## Structure & liquidity

| Term | Meaning |
|---|---|
| **BOS** | Break of structure (platform: close beyond lookback extreme) |
| **CHoCH / MSS** | Change of character / market structure shift (define before automating) |
| **SMT** | Inter-market divergence rule with data_quality |
| **Sweep** | Wick beyond level + close back inside |
| **FVG** | Fair value gap / imbalance geometry |
| **IFVG** | Inversion of FVG (research module) |
| **Order block (OB)** | Candidate defense zone; store as geometry+evidence |
| **BSL / SSL** | Buy-side / sell-side liquidity vernacular |

## Patterns

| Term | Meaning |
|---|---|
| **Rising / Falling wedge** | Present in graph as concept nodes from cheat sheets |
| **Flag / pennant / triangle** | Classic continuation/compression patterns — hints only |

## Platform

| Term | Meaning |
|---|---|
| **Eligible** | All mandatory gates pass; score band per spec |
| **Recommendation** | Immutable versioned geometry; not an order |
| **Dry-run fail-closed** | Live trading blocked unless explicitly configured otherwise |
| **Freqtrade authority** | Sole order execution path |
