The system identifies market structure, liquidity, zones, patterns, and possible institutional-style traps from raw candle data.

B. SCENARIO GENERATION

C. CONFIRMATION AND EXECUTION
The system waits for evidence such as a sweep, displacement, reclaim, break of structure, market structure shift, retest, or rejection before escalating a setup from “interesting” to “actionable.”

D. TRAINING AND CALIBRATION
The repeated quizzes strongly imply that the product should help the trader learn. Historical candles can be hidden, the user can make a directional or no-trade decision, and the platform can reveal the future path and score both the outcome and the quality of the reasoning.

It must preserve invalidated setups, false positives, stop-outs, and the conditions under which a reasonable thesis failed.

The central inferred philosophy is:

“Read what the market is doing around liquidity and structure, describe the evidence, wait for confirmation, manage risk, and learn from both correct and incorrect interpretations.”

The partner appears to want a system that can eventually automate execution but begins by formalizing discretionary visual reasoning. This is compatible with the broader trading-platform direction: Freqtrade and CCXT for execution and exchange connectivity, a private Python service for strategies and data, Telegram for interaction, and a later GUI for visual inspection and control.

8. PROPOSED SETUP STATE MACHINE
======================================================================

A useful platform state machine based on the images is:

STATE 1: CONTEXT IDENTIFIED
- Trend/range and higher-timeframe bias are known.

STATE 2: LOCATION IDENTIFIED
- Price approaches liquidity, an order block, FVG, supply/demand, pattern boundary, or CRT high/low.

STATE 3: EVENT OCCURS
- Sweep, breakout, rejection, displacement, or zone touch.

STATE 4: CONFIRMATION PENDING
- System waits for reclaim, MSS, CHOCH, BOS, retest, or close acceptance.

STATE 5: SETUP VALIDATED
- Entry, invalidation, and target can be defined with acceptable risk/reward.

STATE 6: EXECUTION ELIGIBLE
- Risk limits, liquidity, spread, slippage, and portfolio exposure pass.

STATE 7: ACTIVE TRADE
- Position is monitored.

STATE 8A: TARGET/EXIT
- Outcome recorded.

STATE 8B: INVALIDATION/STOP
- Failure is recorded, including possible reverse setup.

STATE 9: POSTMORTEM
- System compares actual sequence with the expected one.

This event-driven model is preferable to calculating one continuous “smart money score.” It preserves causality and lets the trader see exactly what happened.

9.1 BASIC QUIZ MODE

- Ask for confidence from 0 to 100.

9.2 STRUCTURED REASONING MODE

Ask the user to identify:

- Market regime.
- Higher-timeframe bias.
- Nearest liquidity above and below.
- Last BOS/CHOCH/MSS.
- Relevant FVG/order block/supply-demand zone.
- Entry trigger.
- Invalidation.
- Target.
- Reasons to avoid the trade.

9.3 EXECUTION-QUALITY MODE

The user draws entry, stop, and target. The platform calculates:

- Planned reward/risk.
- Actual maximum favorable excursion.
- Actual maximum adverse excursion.
- Whether stop placement was structurally valid.
- Whether the target was realistic.

9.4 COLD-READ MODE

- Exactly 20 bars, matching the image inspiration.
- No indicators.
- Symbol and time hidden.
- One timeframe only.

9.5 MULTI-TIMEFRAME MODE

- Higher timeframe for context.
- Lower timeframe for trigger.
- Useful for 4H/30M and 15M examples seen in the images.

9.6 FAILURE REVIEW MODE

Show only failed trades and ask:

- Was the setup valid?
- What invalidated it?
- Was the trade early?
- Was opposing evidence ignored?
- Did price accept beyond the zone?
- Was the stop too tight?

9.7 CALIBRATION OVER RAW ACCURACY

The platform should not reward guessing. A trader who selects “no trade” when evidence is insufficient should often score better than a trader who guesses the next candle correctly for weak reasons.

9.8 AVOID LOOKAHEAD BIAS

All features and screenshots used in a quiz must be generated using only data available before the cutoff. Future pivots, repainted zones, and indicators that require future candles must be prohibited or clearly marked.
